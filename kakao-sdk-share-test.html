카카오 표시 제한: 위 8개 항목은 공유 요청에 모두 포함하지만, 카카오 기본 피드 카드는 제목과 설명을 합쳐 최대 4줄만 보여줘. 카드 이미지나 제목을 누르면 8개 항목 전체를 볼 수 있고, 아래 원문 공고 버튼을 누르면 고용24로 이동해.

여러 명 전송: 공유창에서 2명 이상 선택해 봐. 카카오 공식 공유의 기본 한도는 최대 10개 대상이지만, 앱 권한과 사용 환경에 따라 선택 화면은 달라질 수 있어.

전송할 때는 PC 크롬의 카카오 계정으로 공유 대상을 선택해. 긴 영문 주소는 메시지에 표시되지 않고, 원문 공고 보기 버튼에만 연결돼. 카드에는 공개된 채용정보만 넣어 줘.

원문 버튼이 연결되지 않으면 카카오디벨로퍼스의 제품 링크 관리 → 웹 도메인에 https://careercounselor1984-code.github.io 등록 상태를 확인해야 해. 화면에 나타난 링크를 직접 확인하려면 원문 연결 주소 열어보기를 눌러봐.
