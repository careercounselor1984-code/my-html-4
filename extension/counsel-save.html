상담일지 저장 확인

취업지원서비스기간에 저장한 상담일지를 확인해 이 브라우저에 기록합니다. IAP 수립단계와 저장 여부를 확인하지 못한 건은 완료 기록에 넣지 않습니다.

최근 감지 기록을 확인하고 있습니다.

점검 버튼을 매번 누를 필요는 없습니다. 패널을 닫아도 저장 동작을 자동 감지하며, 저장을 눌렀을 때만 최대 20초 동안 성공 안내를 확인합니다. 일반적인 ‘저장되었습니다’ 문구만 나오면 확인 보류로 남습니다. 실제 전산의 성공 응답과 연결하는 현장 점검 단계입니다.

저장 확인 이력

표시한 날짜는 실제 상담일이며 확인 시각은 전산 저장 성공을 감지한 시각입니다. 같은 상담일지를 다시 저장한 경우도 저장 이력으로 남으므로 이력을 곧바로 상담 횟수로 세지 않습니다.

21일 알림·회차별 상담 횟수 판단·일정표 연계는 아직 적용하지 않았습니다. 브라우저의 확장프로그램 데이터를 지우면 이 기록도 삭제됩니다.
