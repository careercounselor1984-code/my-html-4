국취 전산 상담 도우미 1.4.24 · 보안 강화 업데이트

[이번 버전에 적용]
- 기존 1.4.22 IAP·구직준비도 Work24 입력 알고리즘 유지. 최종 저장/제출 자동화 없음.
- 확장프로그램 저장소의 전송 대기정보를 마지막 전송 시각 기준 72시간 뒤 자동 정리합니다.
- 상담일지 저장확인 이력 90일/최대 250건, 저장 상태 7일, 훈련 검증표 180일/최대 120건, 훈련 계획날짜 7일 보관.
- 보안·보관자료 관리 메뉴에서 전송 대기자료/전체 자료를 수동 삭제할 수 있습니다.
- 통합본 메시지는 source 및 origin 확인, 전송 시각 및 크기·자료 형식을 점검합니다.
- 보안 강화를 위해 통합본 GitHub Pages의 자동 스크립트 삽입 범위를 /my-html-4/ 아래로 좁히고 (호스트 권한 자체는 GitHub Pages 원본 주소 범위 유지), 로컬 파일은 이름에 ‘상담일지 통합본’이 있는 문서에서만 처리합니다.
- 직접 전송 fallback에서 동일 출처 프레임만 허용합니다.
- 구직준비도 자동입력 전 상담사 참여자 확인 안내를 추가했습니다.
- IAP 자료에 iapNo/IAP_NO/participantIapNo가 있으면 현재 화면의 등록번호를 추가로 대조합니다. 전송자료에 등록번호가 없다면 기존의 수동확인을 유지합니다.

[중요한 한계]
- 이 버전은 실제 기관/고용24의 확장프로그램 사용 승인을 대체하지 않습니다.
- 로그인 상태의 Work24 화면/내부 Nexacro 데이터에 접근하므로 운영기관 정책을 확인해야 합니다.
- 개인정보를 암호화해서 저장하는 것은 아닙니다. 보관기간 최소화로 노출 범위를 줄였습니다.
- 통합본 페이지에 전달된 정보는 통합본 자체 스크립트가 처리합니다. 통합본 서버/앱 보안은 별도 점검 대상입니다.
- file:// 접근 허용이 필요한 로컬 통합본 사용자에게는 크롬 확장프로그램 상세에서 별도의 파일 URL 접근 허용이 필요합니다.
- 패키지 코드는 구문/단위/정적 검증만 수행했습니다. 실제 Work24 및 통합본 환경의 동작 검증이 필요합니다.

[교체 시 주의]
- 크롬 웹스토어 업데이트 또는 수동 배포 시 기존 확장프로그램을 중복 설치/활성화하지 마세요.
- 기존 자료 중 만료 시각이 지난 항목과 날짜 정보가 없어서 안전하게 유효기간을 판단할 수 없는 항목은 설치/실행 시 정리됩니다.
- 중요한 보관자료가 필요하면 업데이트 전 기존 자료 보존 정책을 먼저 확인하세요.
- 통합본 전체 새로고침(Ctrl+Shift+R), Work24 새로고침 후 점검하세요.
