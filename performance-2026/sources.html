자료 대조 원칙

법령·고시는 실제 서비스 제공과 처분의 기준으로, 평가문서는 해당 연도 실적 산정 기준으로 확인합니다. 평가 QA가 더 좁은 인정 범위를 정한다고 해서 필요한 상담서비스를 제한하는 근거가 되는 것은 아닙니다. 같은 내용에 차이가 있으면 적용일·적용대상을 확인하고 담당 고용센터에 문의합니다.

아직 해석 확인이 필요한 항목

  • 평가지표의 일부 연도·배점·산식 참조 ID 불일치.
  • 평가기간은 2025.11.1.~2026.10.31.로 안내하지만 A2의 날짜 비교에는 엄격한 부등호(<) 표기도 있어, 경계일 종료 건의 산정은 로우데이터와 담당기관 확인이 필요합니다.
  • ‘다른 종류 사업 중복 인정’과 ‘일경험 외 타사업 1회’가 병존하는 집계 범위.
  • 정확히 1개월인 일경험 과정 또는 개인 참여기간의 연계 가점 처리.
  • 중간점검 안내 이후 최종평가 수기 검증결과·추가 공지.

확인일: 2026.10.21. 법령은 국가법령정보센터 공식 원문을 직접 조회·대조했습니다. 실시간 법령 API 자동연동·개정 자동 갱신 기능은 아닙니다. 이 안내는 첨부 평가자료 3종, 업무매뉴얼 1종, 위에서 확인한 관련 법령·고시 범위의 업무 참고 최종 정리본입니다. 매뉴얼 전체의 모든 업무를 대체하지 않습니다.
