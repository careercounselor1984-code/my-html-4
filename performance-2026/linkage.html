연계 가점

대상 사업·연계 및 참여 증빙·집계

2026년 평가기간: 2025.11.1.~2026.10.31. · 이후 연도에 그대로 적용하지 않습니다.

근거자료·법령 확인 기록 · 평가실적 인정과 실제 상담 처리를 따로 확인하세요.

검색 결과가 없습니다. 다른 단어로 검색하거나 검색을 초기화하세요.

회색: 평가문서 기준파란색: 매뉴얼·법령에 따른 상담 처리
평가 기준연계 가점 / 가장 먼저 확인

연계 가점은 ‘종료자 + 기관 연계 + 실제 참여’

  1. 대상자 확인: 2025.11.1.~2026.10.31. 종료자. 기간만료·중단·취업 등 종료사유를 포함합니다. 연계일 자체가 평가기간 안에 있어야 하는 것은 아닙니다.
  2. 기관 연계 증빙: 추천서 등 우리 기관이 연계했다는 자료를 확보합니다.
  3. 실제 참여 증빙: 참여확인서 등 참여했다는 자료를 확보합니다.
  4. 입력·제출: 고용24 IAP등록/관리 화면에 입력하고 첨부합니다. 첨부가 안 되면 별도 증빙을 고용센터에 제출합니다.

추천서와 참여확인서 모두 필요합니다. 양식이 없으면 문자·이메일 등으로 두 사실을 입증할 수 있습니다. 상담일지 내용만으로는 인정되지 않습니다.

불인정 예시 상담일지에 “일경험 연계함”만 적고 참여확인서만 보관 → 기관 연계 증빙이 부족합니다.
확인 가능한 예시 기관 추천 메일 + 실제 참여확인서 + 고용24 입력·첨부 → 나머지 대상·기간 기준까지 검토합니다.

평가 기준연계 가점 / 인정 사업

어떤 연계가 인정되나요?

일경험

1개월 초과 참여자가 기준입니다. 프로그램 자체가 1개월 미만이면 해당 과정을 수료한 경우입니다.

프로그램이 정확히 1개월인 경우, 개인이 정확히 1개월만 참여한 경우의 처리는 첨부자료에 명확하지 않습니다. 자동 인정으로 안내하지 않고 고용센터에 확인합니다.

타사업

타 부처·지자체·유관기관·공공기관 사업 연계가 대상입니다. 예: 신용회복위원회 채무조정, 정신건강복지센터 상담, 소상공인 융자, 근로복지공단 직업훈련 생계비대부 신청, 해외취업연수, 창업지원 등.

2026 업무매뉴얼 166~179쪽의 예시 사업 또는 그에 준하는 사업인지 확인합니다. 사업 이름만으로 가점을 확정하지 않습니다.

제외

  • 현장실습을 일경험으로 연계한 경우
  • 공공근로·직접일자리사업 연계
  • 참여자가 직접 찾아서 문의하거나 먼저 지원한 경우

평가 기준연계 가점 / 중복 집계

같은 사람이 여러 사업에 참여하면?

집계 기준은 IAP번호입니다. 다른 종류의 사업 참여는 중복실적을 인정하지만, 같은 사업(프로그램) 반복 참여는 1회라고 안내합니다.

원문은 이어서 “일경험 연계 실적은 2회까지만 인정, 일경험 외 타사업 연계는 1회만 인정”이라고 규정합니다.

확인 필요: ‘다른 종류 사업 중복 인정’과 ‘타사업 1회’의 적용 범위가 함께 적혀 있어, 한 사람의 서로 다른 타사업 여러 건을 몇 건으로 집계하는지는 첨부 문구만으로 확정하기 어렵습니다. 임의 합산하지 말고 고용센터의 집계 해석을 확인합니다.

컨소시엄은 구성기관 실적을 합산합니다. 10~19건 1점 / 20~39건 2점 / 40건 이상 3점입니다.

평가 기준연계 가점 / 심리상담

심리상담은 기관 종류와 증빙을 확인

  • 타 부처·지방정부 심리상담센터 연계 범위를 확인합니다. 이를 제외한 민간운영기관 심리상담 연계는 불인정입니다.
  • 심리검사를 특강·집단 형식으로 진행하는 경우는 불인정입니다.
  • 추천서 또는 전산망 ‘전문심리상담정보’ 입력으로 연계사실을 확인할 수 있으며, 참여확인서 증빙도 필요합니다.
  • 참여자에게 필요한 수요를 먼저 확인합니다. 불필요하거나 무리한 연계는 불인정될 수 있습니다.

상담 처리

실제 연계업무는 ‘필요성 → 동의 → 의뢰 → 참여 확인’

  1. 취업을 막는 심리·돌봄·채무·주거 등의 어려움과 지원 필요성을 확인합니다.
  2. 참여자에게 목적·연계기관·공유할 정보를 설명하고 필요한 동의를 받습니다.
  3. 추천서·공식 전산의뢰 등으로 연계하고, 실제 참여 여부와 결과를 확인합니다.
  4. 상담일지에는 필요성과 경과를 기록합니다. 평가 가점용으로는 연계 증빙과 실제 참여 증빙도 별도로 확보합니다.

매뉴얼 154쪽은 심리상담 추천 시 수급자의 동의와 추천서(서식 32)를, 172쪽은 사례관리 의뢰 전 개인정보 이용·제공동의서 안내를 제시합니다. 178쪽은 창업지원 추천 후 대상 확정과 월 1회 이상 모니터링을 안내합니다.

법령상 연계 가능한 기관의 범위와 평가 가점 인정기관의 범위는 같지 않을 수 있습니다. 서비스가 필요하면 지원하되 가점은 QA의 기관·사업·증빙 기준을 따로 확인합니다.
