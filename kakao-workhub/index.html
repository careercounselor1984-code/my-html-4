시험판 · 실발송 없음가상 자료만 사용
운영 전 점검: 이 화면은 실제 카카오 메시지를 발송하거나 실제 내담자 정보를 조회·저장하지 않습니다. 알림톡 발송은 공식 딜러사·승인 템플릿이 필요하고, 고객파일 API 사용에는 별도 동의와 권한이 필요합니다. 본인 확인 정보·전화번호·상담 기록을 시험판에 입력하지 마세요.

③ 상담 일정 시스템과 서버 간 안전한 발송 큐 연결

챗봇 연결 단계

현재는 화면 안에서만 동작하는 시연 버전입니다. 카카오톡 채널에서 실제로 자동 응답하려면 챗봇 관리자센터의 시나리오 또는 스킬 서버 연결이 필요합니다.

운영 원칙

법령과 운영매뉴얼의 최신 버전을 확인하지 못한 질문은 담당 상담사에게 연결합니다. 주민등록번호·연락처·상담내역·계좌번호 등을 챗봇에 입력하도록 요청하지 않습니다.

카카오 고객파일 API와의 차이

이 분류표는 자체 상담사 내부 관리의 모형입니다. 카카오 고객파일에 대상자를 실제 등록하려면 카카오 로그인·채널 친구 여부·고객 관리 API 정책 동의 등 조건을 충족해야 합니다. 내담자 목록을 바로 카카오톡 주소록으로 전송하는 기능은 제공하지 않습니다.
