# 좋은일자리 카카오 업무허브 v0.1

이 디렉터리는 기존 상담일지 통합본, 채용정보 도우미, 카카오톡 공유 기능을 수정하지 않고 별도 시연 페이지를 제공합니다.

## 주소
- 시험판: https://careercounselor1984-code.github.io/my-html-4/kakao-workhub/
- HTML: ./index.html
- 공용 카카오 JavaScript 키 설정 참조: ../kakao-share-config.js (기존 파일 재사용)

## 현재 제공 기능 (모두 시험판)
1. **알림톡 준비**: 상담 예약 확정, 일정 변경, 서류 요청, 접수 확인 문구 생성·미리보기·복사. 실제 발송/예약/승인 연동 없음.
2. **국취 안내 챗봇**: 6개 FAQ 주제 키워드 응답, 기타 질문 상담사 연결 안내, 카카오 OpenBuilder SkillResponse 2.0 모양의 JSON 예시 복사. 카카오 채널 챗봇이나 실제 스킬 서버와 연결되지 않음.
3. **고객 유형 분류**: D01~D12 가상 코드만으로 청년/중장년/재참여, 취업/훈련/면접 조건 필터링 및 CSV 내보내기. 실제 사용자, 전화번호, 채널 친구, 동의 데이터 없음.
4. **카카오맵**: 주소 또는 장소명 입력 시 지도 SDK에서 주소/키워드 검색, 마커, 카카오맵 검색 링크 생성. 지도 API가 활성화되지 않았거나 SDK를 불러오지 못하면 외부 카카오맵 검색 링크 사용 가능.

## 운영 전 필수 작업
- **알림톡**: 공식 딜러사 이용 계약, 발신 채널 검증, 템플릿 심사, 발송 큐/재시도/이력·동의/정보보호 체계
- **챗봇**: 카카오 챗봇 관리자센터 계정/채널 연결 및 스킬 서버; 정확한 2026/2027 국취 매뉴얼 검증 후 답변 추가
- **고객관리**: 개인정보 처리 근거 및 수신동의 확인, 역할 기반 접근 제어, 카카오 로그인/채널 친구 상태, 카카오 고객파일 API 정책 동의 및 권한, 안전한 서버 측 동기화
- **지도**: 2026-07-21 이후 카카오맵 API 이용정책·무료쿼터·과금 설정 확인, 필요 시 지도 활성화
- 실데이터 연동 시 데이터 저장 위치, 보유 기간, 센터별 권한, 삭제 이력, 감사 로그 및 취업지원 관련 개인정보 처리 지침 검토
- REST API 키, Admin 키, 딜러사 토큰 및 Supabase Service role 키는 HTML/JS/GitHub에 절대 넣지 말 것

## 진단
- GitHub에 파일 생성 확인
- 브라우저 JS 구문 검사 통과 (기능별 실브라우저 클릭 및 Kakao API 권한 테스트는 별도 필요)
- 테스트는 비식별 샘플 데이터만 사용
- 현재 상담일지·일정표의 실데이터와 DB 스키마는 변경하지 않음
