# 핵심 생성·산정 로직 서버 이전 마무리

| 화면 | 인증 서버에서 처리 |
| --- | --- |
| 일반 초기상담 Ⅰ·Ⅱ | 종합의견 자동 생성 (기존 이전 유지) |
| 심리검사 L·S | 종합 추천, 지원방향, 직무적합성, L형 성격·생활사 종합반영, 종합의견 |
| 일반 IAP | 종합의견 자동 생성 (기존 이전 유지) |
| 구직촉진수당 | 지급액·소득별 산정 (기존 이전 유지) |
| 특성화고 초기상담 Ⅰ·Ⅱ | 중첩 화면 종합의견 자동 생성 및 구형 Legacy 생성기 제거 |
| 특성화고 심리검사·IAP | 중첩 L·S 추천·종합의견, IAP 종합의견, 통합 상담사 의견 |
| Ⅱ유형 취업활동비용·기타 수당 | 훈련참여지원수당 자동액, 참여장려수당 산정, 취업성공수당 단계별 금액 |

새 서버 코드는 공개 저장소에 넣지 않는다. 기존 직원 토큰·활성 계정과 직원·비밀번호 변경 요구·등록기기와 만료를 서버가 확인한다. 동일 계정 재로그인도 이전 로그인에서 시작한 요청을 부모 인증 세대 검사로 폐기한다.

특성화고 내부 프레임의 응답을 기다린 뒤 통합 출력·복사를 진행한다. 실패한 새 요청 대신 이전 출력을 복사하는 fallback을 제거했다. 수기 의견은 유지하고 입력·초기화·직접 수정·지연 응답을 검사한다. 심리검사 추천 갱신은 350ms 후 최신 입력인지 확인하며 진행 중 같은 요청은 합친다. PDF 추출은 기존 브라우저에서 유지한다.

전송 필드는 작업별로 제한한다. 이름·등록번호·전화번호·원본 PDF·전체 기록을 새 요청에 포함하지 않는다. 자유입력에 개인정보를 직접 넣으면 해당 문자열은 전송될 수 있다. 새 서버에는 기록 저장이나 입력/출력 로그를 추가하지 않는다. 인증 조회만 기존 데이터베이스를 사용한다.

무료 요금제를 유지한다. 유료 전환·결제 변경·외부 AI API 사용은 없다. 인스턴스별 요청 제한은 보조 보호이며 전역 요금 상한은 아니다.

공개 기준의 점수/등급 표시, RIASEC 기초 설명, 날짜·기간 산술, 휴일/인정일수 UI, 입력·저장·전산전송 어댑터, 선택문구와 최종 출력 서식은 브라우저에 둔다. 단순 계산마다 통신을 요구하지 않으며 출력 문장 자체는 사용자에게 보인다. 채용정보/API 연결, 안내문·프롬프트·추천서/컨설팅 출력 템플릿도 동일하다.

이번 범위는 통합본이다. 별도 확장프로그램 패키지는 수정하지 않는다. 기존 연결은 회귀 검사한다. 과거 공개 Git 기록·내려받은 사본은 회수할 수 없고 공개 화면·출력의 모방이나 독자 재구현까지 차단할 수 없다.

검증: 서버950건의 기존 결과 일치/경계 및 스키마·인증·기기·출처·크기·오류 검사. DOM에서 L·S 및 중첩본, 학교 초기 Ⅰ·Ⅱ, 학교 통합 출력, 수기 의견, 지연/실패 및 이전 기록 복사 금지 검사. 기존 일정표·인정일수·저장/복원·전산 전송·로그인을 포함한 로컬25개 회귀 검사. Chrome에서 일반 L·S와 학교 초기/심리검사·IAP의 실제 srcdoc 중첩 및 인증 브리지 모의 검증을 CI 실행.

실제 직원 계정의 종단 간 응답시간과 현장 전산 입력은 실사용 확인이 필요하다.
