# 훈련 회차·예정일수와 상담기록 보완

## 사용 흐름

1. IAP의 ‘직업훈련 넣기’ 또는 내일배움카드의 고용24 검색에서 과정을 검색한다.
2. 결과에 개강 회차를 표시한다. ‘다른 회차 보기’에서 같은 과정의 다른 개강일을 선택할 수 있다. IAP 검색은 이전·다음 페이지도 제공한다.
3. IAP에 넣을 때 공개 훈련시간표를 조회한다. 과정·회차·기관과 전체 훈련일수를 대조하고, 시간표 날짜 수까지 일치한 경우에만 자동으로 확인된 일정으로 사용한다.
4. 수업 날짜를 각 IAP 참여기간에 나누어 예정일수를 계산한다. 공휴일 또는 주말이라도 공식 시간표에 수업이 있으면 포함한다. 점심·중복 교시는 훈련일로 중복 계산하지 않는다.
5. 공개 시간표가 없거나 불완전하면 평일 기준 예상값으로 표시하며 자동 인정횟수 연결을 보류한다. 수업요일·휴강일·보강일을 확인하면 같은 과정의 분할 행에 함께 반영된다. 공식 전체일수가 제공된 경우 계산한 전체일수와 맞아야 자동 연결된다.
6. 원격훈련은 날짜 수 대신 전체 훈련시간과 수료예정일을 입력한다. 수료예정일이 포함된 지급주기에만 40시간 기준 1개/2개를 계획에 반영한다. 실제 수료·출석에 대한 이행 인정은 별도 확인한다.

시간표 날짜, 조회 시각, 원래 과정·회차, 수업요일과 조정일을 IAP의 `trainingPlan`에 저장한다. 저장/복원·백업·행 복사·기간 분할·전송자료에 포함한다. 기존 수동 인정횟수는 복원 후에도 유지한다.

## 함께 수정한 내용

- 재진단을 포함한 회차는 3개, 일반 회차는 2개 기준으로 계산판과 사전점검을 맞췄다.
- 재진단 건강상태 ‘매우 어렵다’도 화면에서 편집한 건강 제약 추천 의견을 출력한다.
- 내일배움카드의 근로·사업자 기본값을 미확인으로 바꾸고 확인 체크를 해제하면 확인완료 문구를 제외한다. 안내·확인 체크를 기본으로 켜지 않는다.
- 구직촉진수당의 비율 선택지에 ‘50% 이상·전부 미만 이행’과 ‘50% 미만 이행’을 명시했다.
- 취업특강의 전체 서비스기간 2회 인정 한도를 사전점검한다. 참여 자체를 제한한다는 뜻은 아니다.
- 참여장려수당은 2026년 신청자와 2025년 신청자를 구분한다. 기존 구형 클라이언트 요청은 서버에서 종전 2026년 기본값으로 처리한다.
- 신청 여부 미확인 시 신청내역을 확인했다고 출력하지 않는다. 종료 안내문에도 신청연도별 횟수 차이를 명시한다.
- 오래된 HRD-Net 명칭과 개발계획 설명을 정리하고, 방문상담 기록과 신청 기록의 용도를 구분했다.

기준: 사용자 제공 국민취업지원제도 업무매뉴얼(2026.1) 인쇄 81·196~198·205·219쪽 및 고용24 참여장려수당 현행 안내. 법령 API 인증값 없이 국가법령정보센터 공식 본문도 확인했다.

## 서버 구성과 배포 순서

새 `work24-training-schedule` 함수는 공개 고용24 과정·시간표만 읽는다. 입력은 과정 ID·회차·기관 ID이며, 상담사나 내담자 개인정보를 받지 않는다. 외부 주소는 고정하고 공개 상세페이지의 과정 신원을 검증한다. 사이트의 일반 공개 조회 절차를 사용하며 회원 로그인·직원 전산 접근을 하지 않는다. 공개 페이지의 개인 이름·연락처·본문 전체를 브라우저로 되돌리지 않는다.

공개 검색 서비스와 같은 방식으로 `verify_jwt: false`로 배포하도록 준비했다. 허용 Origin, 입력 형식, 동시 요청 수와 캐시를 제한한다. 현재 운영 배포는 승인 대기 상태이며 이 문서는 배포 완료를 의미하지 않는다.

순서:

1. 기존 `journal-protected-core`에 신청연도 선택을 처리하는 변경을 배포한다. 기존 인증·직원/기기 검증 및 다른 계산 엔진은 유지한다. 원본과 수정본은 점검 작업 폴더에서 별도로 보관하며 공개 저장소에 보호 계산 코드를 추가하지 않는다.
2. `supabase/training-schedule/`의 새 `work24-training-schedule` 함수를 배포한다.
3. 서버 읽기 전용 조회를 재확인한 후 프런트엔드 변경을 병합·배포한다.

서버 변경이 준비되기 전에 프런트엔드를 배포하면 신청연도 요청 또는 시간표 조회가 실패하므로 위 순서를 지킨다.

## 검증

- 기존 56개 회귀검사 모두 통과(통합본 34개·일정표 22개).
- 새 검사: 시간표 파서, 불규칙·주말 일정과 회차 분할 일수 보존, 원격훈련 40시간·수료예정일 경계, 실제 IAP DOM의 다른 회차 선택·7/6일 분할·저장복원, 상담기록 문구 수정.
- 실제 Chrome에서 PC/모바일 크기에서 시간표 기반 7/6일 분할·인정횟수·복원 UI 확인.
- 수정한 수당 서버 코드: 신청연도·횟수·상담시간·실시 여부 등 158개 조합, 구형 요청 호환성, 잘못된 연도 거부 확인.
- 새 서버 코드를 로컬에서 실행해 실제 공개 고용24 과정의 공식 26일·130시간과 시간표 수업 날짜 26개 일치 확인. 운영 배포를 거치지 않은 검사다.

실제 내담자의 자료·운영 예약·DB 스키마는 변경하지 않는다. 실제 고용24 전산 저장, 개별 직원의 PC/휴대폰 동시 사용과 최신 시간표 변경은 운영 반영 후 별도 확인 대상이다.
