# 구직인증 만료일의 일정관리 전달

`client-date-source.js`는 전산도우미의 기존 `CLG_COUNSEL_BRIDGE_V113 / PENDING_STATE` 기본정보 중 IAP 번호와 구직인증 만료일만 계정별 임시 저장소로 복사한다. 직접 전산을 호출하거나 새 확장 프로그램 권한을 요구하지 않는다.

승인된 통합본 직원 세션, 같은 창·origin, 유효한 날짜와 24시간 이내 전달 시각을 확인한다. 계정 이메일별로 구분하며 이름·연락처 등 기본정보 전체를 보관하지 않는다. 중복 메시지는 저장 이벤트를 반복하지 않고, 로그아웃하면 임시 자료를 제거한다.

일정표의 별도 본인 인증·등록번호 일치 확인 후 빈 만료일을 보완한다. 다른 직원이나 등록번호에 자동 연결하지 않으며 기존 날짜가 다르면 기존 자료를 유지한다.
