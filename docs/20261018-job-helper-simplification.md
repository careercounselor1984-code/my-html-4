# 채용도우미 1.9.1: API 바로입력 및 날짜별 보관함

직무내용·근무시간은 API 결과만 자동입력한다. API·화면 충돌 판단과 사용자 출처 선택 화면을 제거한다. API 미지원·오류·누락 시 화면 값으로 대체하지 않고 미확인 상태를 유지하며 직접 붙여넣기·편집할 수 있다. 직무내용 입력칸은 여러 줄 텍스트로 변경했다.

단일 근무시간 범위는 API 원문에서 그대로 추출한다. K180132610180002의 실제 응답으로 '(오후) 1시 00분 ~ (오후) 4시 00분'을 확인했다. 복수 교대·요일별 조건은 원문을 유지한다. 직무내용의 XML 줄바꿈 표기도 정리한다.

공고 보관함은 한국시간의 오늘만 기본 표시하고 이전·다음·직접 날짜 선택·오늘 복귀 및 요일을 제공한다. 통합본 공용 보관함도 같은 구조이며 서버 날짜 범위를 한국시간 기준으로 조회한다. 기존 저장 내용을 삭제하지 않는다. 확장프로그램의 100건 자동 잘라내기를 제거해 날짜 탐색 중 과거 기록을 보존한다. 스마트 채용매칭 화면과 추천 버튼·관련 리소스는 배포에서 제거하고 기존 저장 데이터는 유지한다.

공유·공유 해제만으로 원래 보관 날짜가 바뀌지 않도록 기존 private.job_archive_stamp를 보완했다. 실 DB 트랜잭션에서 날짜 유지 검증 후 전부 롤백했고 기존 함수 직접 호출 권한도 바꾸지 않았다. SQL은 20261018-archive-share-date.sql에 기록했다.

검증: 실제 API 시간·XML 개행, API 전용 및 실패 시 화면 값 미대체, 복수 교대/요일 조건 보존, 확장프로그램 이벤트 바인딩, 오늘/앞뒤 날짜 및 한국 자정 경계·요일, 추천 UI 제거, 100건 초과 보존, 통합본 서버 날짜 범위 및 기존 공유·불러오기, ACK 대기열·메타데이터 회귀 테스트 통과. 브라우저 전체 화면·모든 사이트 조합은 별도 실사용 확인이 필요하다.
