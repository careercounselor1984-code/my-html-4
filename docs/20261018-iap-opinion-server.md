# 일반 IAP 상담사 종합의견 서버 분리

일반 IAP(p05)의 자동 종합의견 분기만 인증된 서버로 이전한다. 기존 종합의견/추천문구 버튼을 사용하며, 비어 있는 의견으로 기록을 생성·복사하면 서버 결과를 기다린다. 직접 작성된 의견은 서버 호출 없이 기존 형식으로 출력된다.

호출 중 입력·선택·직접작성·초기화 변경을 감지하고 이전 응답을 폐기한다. 버튼 중복 요청을 막고 오류 시 기존 내용을 유지한다. 부모 인증 브리지가 현재 직원 세션과 기기 식별자를 전송하며, 서버가 활성 계정·직원·비밀번호 변경·기기 만료를 검증한다.

전송은 희망직무, 경력 여부, 지역, 시간, 선택한 강점/보완점/지원방향, 구직방법 선택 여부로 한정한다. 성명·등록번호·전체 상담일지는 전송하지 않는다. 자유입력에 개인정보를 직접 넣으면 해당 문자열은 전송될 수 있다. 새 서버는 본문을 저장하거나 로그로 남기지 않는다.

144개 조건의 기존 결과 일치 및 실제 DOM에서 비동기 최종 기록, 수기 의견, 지연 응답, 통신 실패, 로그인 브리지 부재, 버튼 복구를 검사한다. 기존 회귀 검사도 실행한다. 실제 직원 계정으로 종단 간 지연시간은 측정하지 않았다.

학교 IAP(p23), 날짜/기간/인정일수 계산, 최종 출력 서식과 선택형 문구는 이번 이전 대상이 아니다. 과거 공개 코드/이력 회수와 독립적 재구현 방지는 보장할 수 없다. 새 서버 소스는 공개 저장소에 포함하지 않는다. 유료 전환·결제 설정·외부 AI API 추가는 없다.
