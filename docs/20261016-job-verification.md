# 채용도우미 2단계: 공식 API와 상세화면 비교

채용도우미 1.9.0은 기존 work24-counsel-jobs 상세 API 연결을 재사용한다. 인증키는 서버에 그대로 두며 확장프로그램으로 전달하지 않는다. 2026-10-16 실제 공고 K131612610150009 조회에서 직무내용과 평일 9시~18시·주 5일 근무 응답을 확인했다.

화면 URL이 공식 고용24/워크넷 HTTPS 주소이고 구인인증번호가 있으며, 상세 API 응답의 번호도 일치할 때만 비교한다. 기업명·제목 유사 검색으로 다른 사이트의 공고를 임의 결합하지 않는다. 화면과 API가 다르면 출력 값은 미확인으로 두고 원문 두 개를 보존한다. 사용자가 출처를 선택하거나 직접 입력할 수 있다. API 연결 실패 시 화면 값은 보존하며 미수집 항목은 미확인으로 표시한다. 직종명에서 직무내용이나 근무시간을 추정하지 않는다.

보관함 JSON에 확인일·구인인증번호·항목별 확인상태·출처별 원문을 추가했다. 기존 RLS 및 선택 공유 구조를 유지한다. 보관함 화면에 확인 상태·출처 비교를 표시하고 불러오기 시 미확인 항목을 명시한다. 긴 출처 원문을 저장할 수 있도록 기존 JSON 크기 제한만 24,000에서 64,000바이트로 늘렸다.

검증: 실제 API 응답 fixture, 같은 번호 보완, 텍스트 일치, 값 충돌, API 장애, 다른 번호 거절, 외부 도메인 거절, 직종명 추정 금지, 충돌 선택 UI, 보관함으로 전달되는 메타데이터 및 내담자 필드 미전송, 기존 추출/ACK/보관함 DOM 회귀 테스트. 실제 브라우저에서 모든 채용사이트의 로그인·동적 화면을 재현한 검증은 포함하지 않는다. 이미지 OCR은 제공하지 않는다.

설치한 도우미는 v1.9.0으로 업데이트해야 한다. ZIP 제공과 Chrome 웹스토어 게시·심사는 별도다.
