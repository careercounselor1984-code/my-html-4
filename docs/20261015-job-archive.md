# 채용도우미 보관 연동 및 상담사 공유

기존 채용정보&알선 화면에 로그인 기반 내 보관함과 상담사 공유 보관함을 추가했다. 확장프로그램 1.8.27은 보관한 채용공고 필드만 전송한다. 내담자 정보와 로그인 토큰은 브리지에서 전달하지 않는다. 로그인 전 또는 전송 실패 시 대기열을 유지하며, 저장 ACK 이후에만 대기 항목을 삭제한다.

기본은 개인 보관이다. 공고 등록자가 공유를 선택하면 활성 상담사 계정이 조회할 수 있다. 수정·삭제는 등록자에게만 허용한다. RLS와 비공개 스키마의 계정 확인 함수를 적용했다. DB SQL은 job-archive-schema.sql에 기록했다. SQL은 연결된 운영 DB에 반영됨.

검증: 5개 DOM 추출 fixture, 보관함 DOM 기능, ACK 대기열 테스트 통과. DB RLS 활성·4개 정책·anon 조회 권한 없음 확인. 두 계정 역할 전환을 포함한 DB 트랜잭션 검증은 도구 Invalid or expired requestState 오류로 완료하지 못했다. 실제 채용사이트 DOM 전체와 이미지형 공고 OCR은 검증 범위에 포함되지 않는다.

웹스토어 배포는 이 저장소 변경과 별개다. 1.8.27 ZIP을 개발자 대시보드에 올리기 전 기존 설치본은 자동 업데이트되지 않는다.
