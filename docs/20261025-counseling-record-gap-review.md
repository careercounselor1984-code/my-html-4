# 상담기록 누락 위험과 메뉴 보완 점검

점검일: 2026-10-25. 대상: 상담일지 통합본의 메뉴·입력항목·출력문. 기준: 사용자 제공 「국민취업지원제도 업무매뉴얼(2026.1)」. 쪽수는 인쇄쪽 기준이며 PDF 페이지는 8을 더한다. [고용노동부 원문 게시](https://www.moel.go.kr/policy/policydata/view.do?bbs_seq=20251201817).

## 점검 범위

실제 참여자별 고용24/취업지원 전산망 상담일지를 조회한 결과가 아니다. 아래의 ‘부족’은 현재 생성기의 메뉴·기록 흐름이 해당 업무를 충분히 뒷받침하지 않는다는 뜻이며, 상담사가 실제 기록을 누락했다고 단정하지 않는다. 통합본의 저장·복사는 공식 전산망 입력 완료를 뜻하지 않는다.

매뉴얼 69쪽은 전 단계의 상담내용과 제공 서비스를 상담일지·IAP 이행관리에 기록하도록 한다. 상담 시작·종료시간은 즉시 입력하고, 구체적 내용은 상담일로부터 3일 이내 기록하도록 안내한다. 기록에는 목적, 실제 실시·확인한 내용, 결과·결정, 다음 조치를 담는다.

## 이미 있는 기능과 중복 방지

- **IAP 변경**: 현재 ‘검색 → 수정·저장’에서 수정사유를 받고 변경 전후 내역을 저장하며, 최종 출력에도 수정일시·사유·변경내용이 반영된다. 새 변경일지 메뉴를 중복으로 만들 필요는 없다. 실제 변경상담, 전산 계획 변경, 출력·서명·배부·보관 여부는 현장 처리 내용을 확인한다(88–89쪽).
- **초기상담, 심리검사 해석, IAP 수립, 필수 대면상담, 지원서·면접 컨설팅, 채용정보 제공, 카드·훈련과정 추가/변경, 수당 신청, 유예·종료**는 기존 작성 기능을 활용할 수 있다.
- **자기소개서 컨설팅 Pro**의 분석 결과는 상담사가 실제 진행한 상담을 ‘입사지원·자기소개서·면접 컨설팅’ 기록에 반영하면 된다. 분석 버튼을 누른 횟수만큼 별도 상담을 만든다는 뜻이 아니다.
- **직업 세분류 탐색·GPT 도구·메모장·전화번호부·백업**을 혼자 사용한 것까지 별도 상담으로 만들 필요는 없다. 그 결과를 활용해 실제 제공한 서비스가 있다면 해당 상담 기록에 남긴다.
- **상황별 카톡·필수 유의사항 보내기**는 문구 작성 도구다. 생성·복사 사실과 실제 전달·응답·상담 내용을 구분한다. 같은 상담을 여러 메뉴에서 반복 생성해 중복 입력하지 않는다.

## 권장 구조

상위 메뉴를 여덟 개 더 늘리기보다 **정기·수시상담** 한 메뉴에 ‘일반 구직상담 / 훈련 점검 / 미취업 사후관리 / 취업 적응 / 연계 경과 / 추천·알선 후속 / 연락 시도 / 이관’ 목적을 선택하게 하는 구조를 권장한다. 상담일시·방법·목적·확인 내용·결과·다음 조치는 공통으로 두고, 실제 연락 성공 여부와 자료 확인 여부에 따라 문장을 만든다. 이번 변경에서는 이 신규 기능을 구현하지 않고 부족한 기록 흐름을 점검했다.

## 이번에 수정한 추천서 화면

백업·복원과 발신 기관·상담사 설정을 상단 ‘발신정보·백업’ 대화상자로 옮겼다. 작성 영역은 내담자 불러오기 → 성명·주요 이력 → 직무 → 수신 기업·이메일 → 확인한 강점·추천평 → 생성 순서다. 채용 추천/일경험 연계를 선택하며 일경험 입력란은 해당 용도에서만 표시한다. 문체·지원금은 기본 접힌 추가 설정으로 모으고, 본문 복사·Gmail 초안 열기는 미리보기 옆에 배치한다.
