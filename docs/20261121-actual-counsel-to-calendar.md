- 보낸 이력은 해당 상담 탭/메뉴/등록번호/날짜에서 동일한 저장 건을 반복 전송해도 한 번만 기록되며, 다른 상담 건은 각자 기록됩니다.

- 일정표 이력 테이블 배포와 인증 직원/실제 Chrome 환경 검증 전에는 운영 main에 병합하지 않습니다.
