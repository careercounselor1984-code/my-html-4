# IAP 집단상담·AI면접 계획 집계 수정

기존 `집단상담 / CAP@ 집단프로그램` 계획은 구분이 모호한 집단상담으로 처리되어 0개로 집계되었다. `기타 / AI면접`은 프로그램 집계 대상에서 제외되었다. 또한 수료일을 정오로 파싱하면서 지급기간 종료일의 자정과 비교하여, 마지막 날 수료 예정인 프로그램이 지급주기에 포함되지 않았다.

## 변경 동작

- 기존 CAP@ 집단프로그램은 일반 집단상담 2개로 해석한다. 명시적인 `집단상담(2일 이상)`은 2개, `단기집단상담`은 1개를 유지한다. 구분을 알 수 없는 다른 집단상담은 계속 확인 대상으로 남긴다. 달력상 기간 길이로 수료 일수를 추정하지 않는다.
- `기타` 항목의 AI면접(띄어쓰기·영문 대소문자 차이 포함)은 계획상 1개로 집계한다. 고용서비스 기관의 면접 코칭·취업지원 프로그램 참여와 실제 참여 자료는 수동확인으로 안내한다. 이 안내는 전송 차단 사유가 아니다. 그 외 기타 활동에 일괄 인정 개수를 부여하지 않는다.
- 수료일은 날짜 문자열로 지급기간의 시작일·종료일과 비교한다. 해당 지급주기에만 반영하며, 마지막 날과 다음 주기 첫날을 구별한다. 회차별 계산판과 사전점검이 동일한 프로그램 회차 선택 함수를 사용한다.
- 회차별 계산판에도 상담·프로그램의 `activityEligible` 정보를 반영한다. 훈련 일수 규칙은 프로그램 구분이 직업훈련·일경험인 경우에 적용한다.
- 전송 원본의 구분·프로그램명·날짜를 유지한다. 실제 활동 부족 시 기존 전송 차단을 유지한다.

## 기준과 적용 한계

제공된 2026.1 국민취업지원제도 업무매뉴얼 인쇄 196쪽은 지급주기별 기본 2개, 재진단 필수 대면상담 포함 시 3개 계획을 정한다. 198쪽은 2일 이상 집단상담 수료 2개, 단기집단상담·취업특강 1개와 집단상담 수료일의 지급주기 반영을 정한다.

매뉴얼이 AI면접을 별도 항목으로 명시하지는 않는다. 따라서 AI면접은 사용자가 입력한 취업지원 프로그램의 계획 개수로 반영하며, 실제 이행 인정과 수당 지급은 기관 프로그램 참여 및 증빙 확인을 전제로 한다.

## 검증

`tests/iap-program-credit.test.cjs`는 첨부 화면의 CAP@·단기취업특강·기타 AI면접·자격증 응시를 실제 IAP DOM에 입력한다. 2~6회차 합계 2/2/2/2/3개, 사전점검 차단 0건 및 실제 전송 준비 메시지 생성을 확인한다. 마지막 날·다음 주기 첫날 수료, 단기집단상담, 미확인 집단상담·기타 활동, 부족 시 전송 차단도 검증한다. 전송 메시지는 테스트 창에서 가로채므로 외부로 전송하지 않는다.

기존 활동규칙·추천·훈련일수·훈련회차·일경험·시간표·통합본 안전성 검사와 Chromium 실제 화면 검증을 함께 수행했다. CI에 신규 회귀검사를 추가했다.
