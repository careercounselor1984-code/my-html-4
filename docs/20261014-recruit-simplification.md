# 자체모집·홍보관리 개선 — 2026-10-14

- 운영 통합본의 p35만 변경. 기존 저장키, 명단 ID, 연락·심사·일정표 연동 유지.
- 주요 메뉴: 오늘 할 일 / 모집명단 / 홍보활동 / 성과분석. 전산망 대조·보고서는 관련 화면 하위 메뉴, 목표·권한은 관리자 설정.
- 모집경로 선택, 세부경로 입력, 홍보활동 연결 및 일괄 연결/해제. 기존 자유입력 경로와 수기 데이터 보존.
- 새 활동은 연결 명단에서 신청/인정/배정 자동 계산. 기존 활동은 수기 집계 유지. 두 방식은 중복 합산하지 않으며 전환은 사용자가 선택.
- 홍보효과는 동일 기간 유입자의 현재 배정 결과, 운영 실적은 배정일 기준. 보고서의 완료자 전용 분모와 통합분석의 서로 다른 모집단 전환율 오류 수정.
- 경로 / 기관·세부경로 / 방법 / 개별 활동 분석. 10명 미만 또는 진행중 비중이 높은 자료는 성과 확정으로 취급하지 않음.
- 월목표 대비 수치는 월 배정자 기준으로 수정. 지사 업무 요약도 현재 지사 범위를 적용.

## 확인

`GOODJOB_JSDOM=<jsdom module path> node tests/recruit-workflow.test.cjs`

가상 DOM: 최초 로딩, 모든 하위 화면 이동, 모집명단 신규/수정, 기존 메모·경로·온라인배정 보존, 기존 수기값 보존, 월경계 성과, 일괄 연결/해제, 지사범위, 관리자 메뉴.

기존 journal-safety, schedule-tab, stipend-record-output 테스트 통과. 실제 로그인 사용자 데이터와 브라우저 시각 검수는 미실시.

## 사용

1. 홍보활동을 등록한다.
2. 활동 목록의 ‘명단 연결’에서 실제 해당 활동으로 유입된 사람을 선택한다. 개별 모집명단에서도 연결 가능.
3. 기존 활동은 필요 시 수정창에서 ‘연결한 모집명단으로 자동 계산’을 선택한다. 일부만 연결한 상태라면 실적이 적게 보이므로 연결 범위를 확인한다.
4. 성과분석에서 기간·지사·분석 기준을 선택한다.

자동 집계의 신청 확인: 신청일/공문발송일/인정일 또는 심사중·불인정·신청취하·배정 상태. 인정일이 없더라도 배정 완료 상태는 인정에 포함한다. 불확실한 신청취소만으로 신청 여부를 추정하지 않는다.
