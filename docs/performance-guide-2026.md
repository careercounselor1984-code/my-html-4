# 2026 성과평가 길잡이 v2

상담사가 필요한 평가·상담 처리 기준을 업무별로 확인하도록 독립 HTML 11페이지로 구성했다. 첫 화면은 종합안내, 이후 취업·종료 / 알선 / 조기취업 / 임금 / 고용유지 / 일경험 / 연계가점 / 만족도·우수사례 / 점검·증빙 / 근거·확인사항이다. 29개 안내 카드를 전체 검색 또는 현재 페이지 검색으로 확인한다.

## 출처

사용자 제공: 평가 지표정의서 v2 XLSX, 2026-09-07 2차 점검 유의사항 HWPX, 수기자료검증 가점 QA HWPX, 국민취업지원제도 업무매뉴얼(2026.1) PDF. 각 카드에 시트·지표 ID·셀 또는 문서 항목을 표시했다. 매뉴얼은 인쇄 페이지와 PDF 페이지(본문은 +8)를 병기했다.

공식 원문 직접조회 확인일: 2026-10-21.

- 법률 제19610호: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=253641&efYd=20240209 — 제13·14·15·29조.
- 시행규칙 제486호, 2026-10-14 시행: https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=291203&efYd=20261014 — 제8·9·11·20조.
- 운영규정 제2026-35호, 2026-05-28 시행: https://www.law.go.kr/LSW/admRulLsInfoP.do?admRulSeq=2100000280036 — 제3·8조.

공식 HTML 동적본문은 `lsSideInfoP.do`의 조문별 원문 및 페이지에서 명시적으로 호출하는 `admRulLsInfoR.do`를 통해 읽었다. 검색결과만으로 조문 내용을 추정하지 않았다. 시행규칙 제20조제2항제3호의 2026-10-14 개정된 수당 지급기간 첫날 기준을 별도 표시했다. 법령 API 자동연동 기능은 아니다.

## 구분해서 보완한 내용

- 서비스로 연계 가능한 현장실습/기존참여 일자리와 평가 연계가점 제외를 구분.
- 실제 종료사유와 평가 취업실적 제외를 구분.
- 의무취업종료(주30시간, 노무제공자 월소득250만원 등)와 불완전취업 희망종료(주15시간, 월소득70만원 및 고용보험 예외)를 구분.
- 평가 임금수준의 2026년 월보수258만원과 노무제공자 종료의 실제소득250만원을 구분.
- 평가 F1의 180일 초과와 취업성공수당 근속 및 예외를 구분.
- 평가기간의 IAP종료일 필드와 법령상 취업지원 종료일/서비스 만료일을 구분.
- 중간점검 수기 미반영과 최종평가 인정 판단을 구분.

## 미확정 해석

일부 원본 배점·연도·산식 ID 오류, 타사업 중복집계 범위, 정확히 1개월인 일경험 가점은 담당 고용센터 확인 필요로 유지했다. 자료가 확정하지 않은 조건을 법령에서 임의로 보완하여 확정하지 않았다.

## 구현·재생성

`python scripts/build-performance-guide.py`를 실행한다. 기존 평가 카드의 원본은 `docs/performance-2026-content.json`, 상담 처리 보완과 공통 틀은 생성 스크립트에 있다. 모든 HTML은 인라인 CSS/JS를 포함하며, API·DB·개인정보 입력/전송·영구저장을 사용하지 않는다. 오프라인에서도 상대경로로 페이지 이동·검색 가능하다.

통합본 index.html은 작업탭 복원 이전에 11개 PAGES와 메뉴를 등록한다. 상단 게시판 바로 왼쪽의 녹색 성과평가 버튼과 기존 작업탭 엔진을 사용한다. 인증 및 기존 상담 기능은 수정하지 않았다.

## 검증

- `NODE_PATH=<jsdom 설치경로> node tests/performance-guide.test.cjs`: 11페이지·29카드·출처·HTML ID·내부 링크/fragment·검색·인쇄·초기화·중복 없는 메뉴 등록.
- 기존 journal-safety, tab-f5-shortcut 검사.
- 실제 Chromium으로 데스크톱/390px 모바일 가로넘침·검색·페이지 이동·체크 초기화·인쇄 CSS·시작 시 메뉴 등록과 기존 탭 재사용을 확인한다. 원격 로그인 후 계정별 동작은 검증 범위에 포함되지 않는다.

2026-10-21 사용자가 통합본 게시 및 게시판 왼쪽 상단 배치를 명시적으로 승인했다. 원격 main 최신 상태를 확인한 뒤 해당 배치로 반영한다. 430px 이하 모바일에서는 상단 6개 버튼을 3열 2행으로 배치하여 글자 잘림을 방지한다.

## 상담사 화면 범위 조정

사용자 요청(2026-10-21)에 따라 ESPMS 접속·센터 로우데이터 다운로드·검증요청 팝업 절차 카드(criterion-17)를 삭제했다. 상담사의 증빙 준비, 고용24 입력·첨부 안내, 중간점검과 최종평가 구분 및 마감 확인표는 유지했다.
