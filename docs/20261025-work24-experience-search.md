# 추천서 일경험 프로그램 고용24 검색

위치: 추천서 생성기 → 일경험 연계 → 일경험 프로그램 정보 → **고용24 검색**.

고용24 청년일경험 포털의 공개 목록을 프로그램명·참여기업·운영기관으로 검색한다. 지역·유형·마감 포함 조건과 이전/다음 페이지를 제공한다. 결과에서 ‘불러오기’를 누르면 프로그램명, 원문 유형, 실제 일경험 시작일·종료일을 입력한다. 참여기업과 운영기관은 출처 설명으로 보여 주며, 추천서의 수신 기업·지원자 정보는 변경하지 않는다.

모집기간, 사전직무교육기간, 일경험 참여기간을 구분한다. 공개 목록에 참여기간이 없으면 이전 날짜를 지우고 확인 후 직접 입력하도록 안내한다. 같은 이름이라도 서로 다른 프로그램 ID·기수는 별도로 표시한다. ESG지원형·기업탐방형 등 원문 유형도 선택란에 추가한다. 검색조건 변경·닫기 후 늦게 도착한 응답은 반영하지 않는다.

‘원문’은 고용24가 제공하는 공개 상세조회 POST로 연다. 고용24 참여 신청·찜하기·로그인 요청은 하지 않는다. 프로그램을 고르는 행위는 추천서 입력만 채우며 신청·참여 확정을 뜻하지 않는다. 개인 지원자의 성명·이력·추천평은 조회 요청에 포함하지 않는다.

서버 함수 `work24-experience`는 고정된 `https://yw.work24.go.kr/d/a/selectWkexPrgmList.do`만 조회한다. 임의 URL을 입력받지 않으며, 검색값·유형·지역·페이지를 제한한다. 기존 함수·DB는 변경하지 않는다. 게이트웨이 JWT 검증을 켠 상태로 공개 anon 키를 사용하고, 요청 출처 제한·동시조회 제한·짧은 결과 캐시를 적용한다. 공개 anon 키는 관리용 키가 아니며, 이 기능은 DB에 접근하지 않는다.

검증: 공개 목록 파싱 및 기간·동일명 기수 분리 테스트, 실제 추천서 DOM의 선택·페이지 이동·수정 응답 방지·누락 날짜 처리, 실제 서버의 프로그램/기업 검색과 400·403·401 응답 확인. 격리 Chrome 1440/390px에서 실제 공개 검색 서버를 조회해 참여기간 반영과 생성 본문, 가로 넘침·실행 오류를 확인했다. 기존 추천서 생성·레이아웃 검사도 통과했다.

출처: [고용24 청년일경험 포털 프로그램 목록](https://yw.work24.go.kr/d/a/selectWkexPrgmList.do).
