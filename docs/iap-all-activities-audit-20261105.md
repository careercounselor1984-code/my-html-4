# IAP 전체 활동 재점검

PR #54 이후 배포본을 기준으로 취업지원프로그램과 구직활동지원 메뉴의 회차 집계, 지급기간 경계, 저장·복원을 재점검했다.

## 추가로 확인한 문제와 수정

1. 심리상담·심리안정·취업상담·클리닉·복지·금융·자격증 응시·특강 등과 일반 구직활동을 지급주기 마지막 날 하루로 입력하면, 정오로 파싱된 활동일과 자정인 지급주기 종료일의 비교 때문에 합산에서 제외되었다. 날짜 구간 교차 및 포함 판단을 달력 날짜 기준으로 통일한다. 교차 결과의 시작·종료도 같은 파싱 방식으로 반환한다.
2. 필수 대면 재진단 상담은 취업지원프로그램 메뉴에도 존재하지만 사전점검은 구직활동지원 표만 검색했다. 두 표의 구분·내용·프로그램명을 함께 검색하여, 프로그램 쪽에 입력한 재진단도 계획으로 인식하고 해당 회차의 필요 활동 수를 3개로 계산한다. 프로그램 표에서 4~6회차 한 구간 안에 지정한 상담 예정일도 허용한다.
3. 창업지원·사회봉사활동은 별도 요건 때문에 자동 합산에서 제외되었으나, 요건을 확인한 상담사가 이를 반영할 방법도 없었다. 각 행의 구체적인 인정요건 확인란을 추가하고 확인한 경우에만 계획상 1개로 반영한다. 활동명·기관·기간·구분과 확인 상태를 묶어 저장하고, 내용이 변경되면 재확인을 요구한다. 실제 이행·증빙은 별도로 확인한다.
4. 여러 회차에 걸쳐 한 회차로 배정할 수 없는 프로그램, 확인되지 않은 기타 활동이 합산에서 빠지는 이유를 사전점검에 표시한다. 장기 프로그램은 회차 선택·기간분할을 안내하고, 기타 활동은 내용을 확인한 뒤 구직활동지원 계획에 횟수와 기간을 입력하도록 안내한다. 일괄 자동 인정하지 않는다.
5. 현재 회차 표시도 달력 날짜로 비교하여 회차 시작일 오전에 전 회차·시작 전으로 잘못 표시되는 경우를 방지한다.

## 메뉴별 점검 결과

| 항목 | 점검한 동작 |
| --- | --- |
| 심리상담·심리안정·취업진로상담·취업상담·이력서/자기소개서클리닉 | 단일 회차의 계획 1개 및 첫날·마지막 날 하루 계획 |
| 복지지원·금융지원·자격증 시험응시·전문성 향상·단기취업특강 | 단일 회차의 계획 1개 및 저장 후 복원 |
| 단기집단상담·2일 이상 집단상담·고용/복지/금융 집단프로그램·기존 CAP | 프로그램별 1/2개와 수료 예정 회차 |
| 기타 AI면접 | 기존 1개 계획 반영과 실제 참여 확인 안내 유지 |
| 직업훈련·일경험 | 회차별 선택한 1/2개, 자동 일정과 수동 선택, 저장 후 복원 유지 |
| 창업지원·사회봉사활동 | 미확인 0개, 명시적 요건 확인 후 1개, 복원 및 활동 변경 시 확인 무효화 |
| 재진단 필수 대면상담 | 두 표에서 모두 검색, 해당 회차 3개 필요, 프로그램 표의 하루 상담일 인식 |
| 일반 구직활동 메뉴 5종 | 입력 횟수, 월 반복 계획, 지급기간 경계 날짜 반영 |
| 불명확한 기타·미분할 프로그램 | 자동 인정하지 않고 제외 이유와 입력 방법 안내 |
| Ⅱ유형 | Ⅰ유형의 월 2/3개 충족 기준을 적용하지 않음 |

## 검증

새 `tests/iap-all-activities.test.cjs`에서 실제 IAP DOM과 활동규칙·훈련·일경험 스크립트를 함께 실행한다. 수정 전에는 심리상담을 지급기간 마지막 날로 입력한 첫 사례에서 1개가 누락되는 실패를 재현했고, 수정 후 메뉴별 경계 날짜·복원·재진단 위치·조건 확인·기간분할 안내·훈련 선택값·Ⅱ유형 사례가 통과했다. 신규 검사를 CI에 포함한다.

동일 사례를 실제 Chromium에서도 실행하고 조건 확인란의 화면을 확인했다. 기존 CAP/AI면접 전송 검사, 활동규칙, 훈련·일경험·시간표, 통합본 안전성 검사도 함께 수행한다. 실제 수당 지급 승인이나 참여자 전산의 최종 입력·저장을 대신하는 검사는 아니다.
